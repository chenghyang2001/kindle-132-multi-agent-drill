實例二是製作 Python 入門教材，主題是依副檔名整理下載資料夾。這是接力模式：教學設計 Agent 先寫課綱和三題練習；通過後，程式 Agent 才讀課綱寫範例程式和測試；接著試學 Agent 照著教材從頭操作。這個實例最能看出多 Agent 的價值：程式 Agent 發現在 Windows 上，教材裡的暫存資料夾路徑 Python 讀不到，退回教學設計修正；試學 Agent 又找出六個障礙，最嚴重的是暫存變數空白時，加上 apply 參數會把課程檔案搬走。主 Agent 同時退回程式和教學設計修正，再請試學 Agent 重驗，前後一共三輪。最後主 Agent 自己驗收，九項測試全部通過，預覽不改檔，也沒碰真實的下載資料夾。
