# 台南兩天一夜方案（主 Agent 整合）

> 整合自 `attractions.md`（景點 Agent）、`transport.md`（交通 Agent）、`budget.md`（預算 Agent）。整合日期：2026-10-30。
> 本方案**只是規劃**：未執行任何訂房、訂票、付款或對外預訂。

## 1. 共同條件

| 項目 | 內容 |
| --- | --- |
| 人數 | 兩位成人（非台南市民，不適用市民免費） |
| 交通限制 | 不開車；用步行、公車（98、2 路）、YouBike 2.0、計程車 |
| 起點／終點 | 台南火車站 |
| 預算 | 8,000 元（兩人合計），**不含往返台南的交通費** |
| 日期 | **未定**。所有營業時間、班次、房價都標「待確認」 |
| 住宿假設 | 火車站周邊平價旅館一間雙人房一晚（例：英王商旅，僅為比價網參考價，未訂房） |
| 排程限制 | **第 1 天不可排週一**（國立臺灣文學館週一休館）；建議平日入住（週末房價可能是平日 2～3 倍） |

## 2. 行程總覽

| 天 | 摘要 |
| --- | --- |
| Day 1 | 火車站 → 98 線到赤崁樓 → 國華街午餐 → 林百貨 → 臺南孔廟 → 下午休息 → 文學館 → 旅館休息 → 神農街晚餐 |
| Day 2 | 旅館早餐、寄行李 → 98 線到安平古堡 → 安平老街午餐 → 德記洋行／安平樹屋 → 休息 → YouBike 到億載金城 → 計程車回火車站 |

## 7. 待確認事項與停止條件

**待確認事項**

1. **出遊日期**：決定後重查全部開放時間與公休；第 1 天避開週一（文學館休館）、避開除夕／初一。
2. **住宿房價**：依入住日重查；平日與週末差 2～3 倍，超過 2,400 元要重新試算。
3. **98 線班次**：一天 7 班，出發日重查時刻表；88／99 是否已併入 98 無官方公告。
4. **2 路公車**：路線頁寫「已變更」，出發前用[大台南公車資訊網](https://2384.tainan.gov.tw/)確認站點。
5. **計程車費率**：資料來自 2022 年媒體報導，未見交通局公告。
6. **步行時間**：全部是估計值，用地圖 App 確認。
7. **德記洋行與安平樹屋是否同一張票**。
8. 國華街、神農街、安平老街個別店家的公休日（如富盛號週四休、邱家小卷米粉週一休）。
9. 旅館是否含早、能否寄放行李。

**停止條件（遇到就停下重新規劃，不硬排）**

- 查到的房價使兩人總計超過 8,000 元。
- 出遊日遇到颱風停班或主要景點休館。
- 98 線停駛或時刻表改到 09:20 班不存在。
