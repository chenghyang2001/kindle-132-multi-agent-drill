# 實例一（ex1-travel）執行報告

## 使用的 Agent

共 4 個：主 Agent（本 session「代理一」）＋ 3 個子 Agent（各自是獨立的 Claude Code，跑在螢幕 2 的 tmux session `ex1` 三格中，bypassPermissions、DISABLE_WRITER_QA_HOOK=1）。

| 格 | 子 Agent | 輸入 | 輸出 | 完成檔 |
| --- | --- | --- | --- | --- |
| ① | 景點 | `out/prompt-景點.md` | `out/attractions.md`（13 個景點，三區） | `out/景點.done` |
| ② | 交通 | `out/prompt-交通.md` | `out/transport.md`（98 線、2 路、計程車、YouBike、步行） | `out/交通.done` |
| ③ | 預算 | `out/prompt-預算.md` | `out/budget.md`（住宿／餐飲／交通／門票，低中高三情境） | `out/預算.done` |
| 主 | 整合 | 三份表＋`plan-template.md` | `out/plan.md`、本報告 | `out/ALL.done` |

## 順序與交接

1. 主 Agent 寫三份 prompt 檔（共同條件、責任、不准做的事、輸出路徑、done 檔指示；三區假設寫進每份）。
2. `wpanes open -Session ex1 -Titles "景點,交通,預算" -Monitor 2`，三格啟動 claude、`/rename ex1-<角色>`。
3. 三格**同時**送一行指令「請讀 out/prompt-<角色>.md 並完整照做…」（書中 3.2 平行）。
4. 主 Agent 用背景 until 迴圈＋Monitor 等 done 檔，期間 `wpanes capture` 抽看畫面；三格都沒有停下來問問題。
5. done 出現順序：預算 07:18:06 → 景點 07:20:23 → 交通 07:20:38（詳見 `timeline.tsv`）。
6. 驗收三份表皆合格，**無退回修正**；`wpanes close -Session ex1`。
7. 主 Agent 整合寫 `plan.md`（七項結構），跑驗收檢查，寫本報告。

## 驗收清單（書中 5.1）

| 項目 | 結果 | 依據 |
| --- | --- | --- |
| 行程包含停留、移動與休息時間，沒有時間衝突 | ✅ | Python 檢查逐時表：Day 1 17 段、Day 2 13 段，衝突「無」；每天兩段以上休息（45 分、1 小時） |
| 費用區分每人與兩人合計，總計不超過預算 | ✅ | 每人 2,989／兩人 5,978（`2400+2200+840+538=5978`），剩 2,022 元 |
| 價格與營業資訊有來源或待確認標記 | ✅ | plan.md 第 4、5、6 節每列附來源；步行時間、計程車車程標「估計，待確認」 |
| 未執行訂房、付款或其他對外預訂 | ✅ | 三份 prompt 明令禁止；三份輸出與 plan.md 均有聲明；主 Agent 只做查讀與寫檔 |
